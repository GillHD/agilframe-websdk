# AgilFrame security

[Русский](SECURITY.md) · **English**

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/GillHD/agilframe-core/security/advisories/new). Use public issues for regular bugs and feature requests.

Include the affected version or commit SHA, the relevant configuration, the impact, and the details needed to verify the report. Remove keys, tokens, participant data, and production addresses. Test only in environments you are authorized to use.

A maintainer uses the private report to clarify the issue, coordinate a fix, and publish an advisory. Follow [GitHub Security Advisories](https://github.com/GillHD/agilframe-core/security/advisories) and upgrade to a fixed version.
