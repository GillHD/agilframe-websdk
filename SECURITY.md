# Безопасность AgilFrame

**Русский** · [English](SECURITY.en.md)

О потенциальной уязвимости сообщайте через [приватный отчёт GitHub](https://github.com/GillHD/agilframe-core/security/advisories/new). Публичные Issues предназначены для обычных ошибок и предложений.

Укажите версию или SHA, конфигурацию, область воздействия и минимальные сведения, необходимые для проверки. Удалите из материалов ключи, токены, данные участников и адреса рабочих окружений. Проверки выполняйте только в среде, к которой у вас есть разрешённый доступ.

Сопровождающий использует приватный отчёт для уточнений, согласования исправления и публикации advisory. Следите за [Security Advisories](https://github.com/GillHD/agilframe-core/security/advisories) и обновляйтесь до версий с исправлениями.
